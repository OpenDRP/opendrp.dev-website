Core Capabilities

Built for Security Teams & CISOs

Phishing & Brand Protection

Detect typosquatting and look-alike domains using first-party dnstwist and shodan connectors. Track SSL titles, favicons, and DNS mutations automatically.

Breach Intelligence

Integrates directly with Have I Been Pwned (HIBP) for monitored corporate domains and employee email accounts. Auto-resolves matched breach findings with canonical asset hierarchy.

Core + Connector Architecture

FastAPI application core handles state, authorization, deduplication, and scheduling. External data sources run as stateless containers communicating securely over HTTP API contract.

Deploy in Minutes

Simple Self-Hosted Setup

bash — docker compose deployment 
# 1. Clone the repository
git clone https://github.com/OpenDRP/opendrp.git
cd opendrp

# 2. Run automated setup wizard (generates CSPRNG secrets)
python setup.py

# 3. Spin up PostgreSQL 17, Redis, FastAPI backend & React SPA
make up

Requires Docker Engine with Compose v2.24+. Production environment enforces pinned releases, MFA for admins, and encrypted settings at rest.
